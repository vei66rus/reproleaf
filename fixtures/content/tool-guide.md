# Review a supplied page

Reproleaf compares the data you provide. It does not establish a search ranking or verify an author's qualifications.

## Save the input

Keep the source date, page URL and export scope. Use the same observations when checking a later change.

## Review a difference

Read the relevant paragraph and its source before making an edit. A missing term does not prove that the answer is incomplete.

## Confirm the result

Repeat the check after the edit. Record what changed and what remains outside the supplied evidence.
